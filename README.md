# Phishing Awareness Training

## 📌 Project Overview

**Phishing Awareness Training** is a cybersecurity awareness presentation designed to educate users about phishing attacks and social engineering techniques.

The training explains how attackers use fake emails, websites, SMS messages, phone calls, social media, and psychological manipulation to steal sensitive information such as passwords, OTPs, banking details, and personal information.

The presentation also provides practical techniques to identify phishing attempts, verify suspicious messages, stay safe online, and respond correctly if a phishing link is accidentally opened.

## 🎯 Objectives

* Understand the concept of phishing and how it works.
* Learn about different types of phishing attacks.
* Identify suspicious emails, links, and websites.
* Understand social engineering techniques used by attackers.
* Learn how to verify suspicious messages independently.
* Follow best practices to prevent phishing attacks.
* Understand what to do after clicking a phishing link.
* Test phishing awareness through an interactive quiz.

## 📚 Topics Covered

### 1. Introduction to Phishing

* Definition of phishing
* Common targets
* Common communication channels
* How attackers exploit trust

### 2. How Phishing Works

The presentation explains the typical phishing attack flow:

**Crafted Message → Appears Trusted → User Clicks Link → Credentials Stolen**

### 3. Types of Phishing

* Email Phishing
* Spear Phishing
* Whaling
* Smishing
* Vishing
* Clone Phishing
* QR Phishing (Quishing)

### 4. Identifying Phishing Emails

Important warning signs include:

* Suspicious sender addresses
* Urgent or threatening language
* Spelling and grammar mistakes
* Unexpected attachments
* Suspicious links
* Requests for passwords or OTPs
* Unrealistic offers

### 5. Checking Email Addresses

Users are taught to inspect:

* Exact domain names
* Spelling mistakes
* Unusual extensions
* Extra subdomains
* Differences between display names and actual email addresses

### 6. Identifying Fake Links

The training explains how to:

* Hover over links before clicking.
* Inspect the complete URL.
* Identify suspicious domains.
* Be careful with shortened URLs.
* Avoid entering sensitive information through unknown links.

### 7. Identifying Fake Websites

The presentation covers:

* Copied logos and designs
* Suspicious domains
* Unexpected pop-ups
* Poor grammar and spelling
* Fake login pages

### 8. HTTPS and the Padlock

The presentation explains that HTTPS provides encryption but **does not guarantee that a website is legitimate**.

Users should always verify the domain and other security indicators instead of relying only on the padlock.

### 9. Social Engineering

Common psychological techniques discussed include:

* Fear
* Urgency
* Authority
* Curiosity
* Greed/Reward
* Trust
* Helpfulness and Reciprocity

### 10. Smishing and Vishing

The training explains phishing through:

* SMS and messaging applications
* Phone calls
* Fake bank calls
* Fake prize messages
* Caller ID spoofing

### 11. Real-World Examples

The presentation includes examples such as:

* Fake bank messages
* Job and internship scams
* Social media phishing
* Fake verification messages
* Fake giveaways
* Account-recovery scams

### 12. Best Practices

Recommended security practices include:

* Think before clicking.
* Verify the sender.
* Check URLs carefully.
* Use strong and unique passwords.
* Enable Multi-Factor Authentication (MFA).
* Keep software updated.
* Report suspicious activity.
* Never share passwords, PINs, or OTPs.

### 13. What to Do After Clicking a Phishing Link

The recommended response is:

1. Close the suspicious website.
2. Do not provide additional information.
3. Change exposed passwords.
4. Enable or verify MFA.
5. Contact the bank if financial information was exposed.
6. Scan the device for malware.
7. Report the incident.
8. Monitor accounts for suspicious activity.

### 14. Interactive Quiz

The presentation includes questions that test users' ability to recognize phishing attempts, including:

* Urgent account-deletion messages
* Suspicious URLs
* Requests for OTPs
* Appropriate responses to suspicious messages

## 🛡️ Key Security Message

The main message of this training is:

**STOP • THINK • VERIFY**

* **STOP** — Don't act immediately.
* **THINK** — Look for suspicious signs.
* **VERIFY** — Confirm the request using trusted and official channels.
